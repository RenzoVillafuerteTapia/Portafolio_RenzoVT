Proyectos

VetCare

Plataforma para una veterinaria: una web de administración para el personal y una app móvil para los dueños de las mascotas, conectadas a una API común.

La API es un monolito modular con arquitectura hexagonal. La web y la app usan tipos TypeScript generados desde el contrato OpenAPI, y el CI impide fusionar un cambio de la API sin actualizarlos.

v0.1.0: autenticación, roles y permisos funcionando en API, web y app móvil.

  • FastAPI
  • SQLAlchemy
  • MySQL 8
  • React
  • TypeScript
  • Expo
  • Docker
  • AWS
  • GitHub Actions
