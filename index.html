Proyectos

VetCare

Plataforma para una veterinaria: una web de administración para el personal y una app móvil para los dueños de las mascotas, conectadas a una API común.

La API es un monolito modular con arquitectura hexagonal por bounded context. La web y la app consumen tipos TypeScript generados desde el contrato OpenAPI, y el CI impide fusionar un cambio de la API sin actualizarlos.

v0.1.0: autenticación, roles y permisos funcionando en API, web y app móvil. En desarrollo: clínica, clientes, mascotas y agenda de citas.
